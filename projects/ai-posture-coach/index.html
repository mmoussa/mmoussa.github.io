AI Posture Coach

An AI-powered posture analysis system using computer vision-based pose detection and LLM-driven reasoning pipelines to generate real-time feedback for the user

AI Posture Coach is a project focused on developing an AI-powered posture analysis system that provides real-time feedback to users.

  • AI
  • Computer Vision
  • LLM
  • Python
  • Streamlit
  • Unreal Engine

Highlights

  • Researched and implemented computer vision-based pose detection techniques to analyze user posture.
  • Developed LLM-driven reasoning pipelines to generate personalized feedback.
  • Integrated real-time feedback mechanisms to enhance user engagement.
